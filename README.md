### Easier appointment rescheduling

Previously, the appointment edit form did not show which clients were linked to an existing appointment. We added an **Edit or reschedule appointment** action for Admins and Schedulers. The form now displays linked clients as checked, read-only selections, so staff can change the date and time while preserving the original appointment and its client links.

Counselor permissions, database structure, and website styling remain unchanged. All 21 automated tests pass using simulated Supabase responses.
